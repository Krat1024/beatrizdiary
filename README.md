# 📔 Daily Diary - Beatriz

Este projeto não é apenas um código, mas um espaço dedicado à minha esposa. A intenção por trás de cada linha de código foi criar um lugar seguro e bonito para que ela possa registrar seus pensamentos, sentimentos e memórias do dia a dia.

## 💝 Dedicatória
Este diário foi construído com todo carinho, pensando na nossa história e no desejo de proporcionar a ela uma experiência visual acolhedora e funcional. Que cada palavra escrita aqui seja um reflexo do nosso cuidado.

## 🚀 Tecnologias e Funcionalidades
* *Interface*: Desenvolvida com React e Vite para máxima rapidez.
* *Estilo*: CSS personalizado com fundo adaptável (Desktop/Mobile) em tons de lilás.
* *Segurança*: Conexão com Supabase para garantir que as memórias fiquem protegidas.
* *Hospedagem*: Deploy automático via Vercel, garantindo que o site esteja sempre no ar.
